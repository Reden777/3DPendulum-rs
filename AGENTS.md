A 3d pendulum (a cord with a bob) that swings realistically and should work for divination. My idea was to allow this through comphrehensive physics simulation:
- angle
- center of mass
- gravity
- drag
- air speed
- weight
- quadratic air drag
- wind speed
and so forth.

integrate randomness from various sources, and add an (optional?) option to use the random.org unauthenticated http api

Tech stack: Translate the three.js + Rapier into headless rust (rapier3d)
